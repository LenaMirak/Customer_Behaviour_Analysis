# Customer_Behaviour_Analysis
Data analystics project showcasing customer behaviour analysis using Python, SQL and Power BI.

📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, explore customer segments, and understand spending trends. It combines Python, SQL, MySQL, and Power BI to transform raw customer data into meaningful business insights.

🛠️ Tools & Technologies

Python — Data cleaning, transformation, and exploratory data analysis

Pandas — Data manipulation and preparation

SQL — Business queries and analytical problem-solving

MySQL — Database management and querying

Power BI — Data visualization and interactive dashboards

Jupyter Notebook — Data exploration and analysis

📊 Project Workflow

Data Exploration: Explore the dataset and understand its structure.

Data Cleaning: Identify missing values, standardize column names, and prepare data for analysis.

Feature Engineering: Create customer age groups and convert purchase frequency categories into numerical values.

Database: Load the prepared dataset into MySQL.

SQL Analysis: Answer business questions using SQL queries.

Visualization: Use Power BI to present customer behavior and purchasing trends.

🐍 Python Analysis

The Jupyter Notebook includes:

Exploratory data analysis and descriptive statistics.

Missing-value identification and handling of missing review ratings using category-level medians.

Column-name standardization.

Customer age-group creation using quartiles.

Purchase-frequency transformation.

Analysis of discount usage and promotional code usage.

Data preparation for MySQL analysis.

🗄️ SQL Business Questions

The SQL analysis explores 10 business questions:

Revenue by Gender — Compare total purchase amounts by gender.

Discounts and Spending — Identify discount users whose purchase amounts are at least the average purchase amount.

Product Ratings — Find the five products with the highest average review ratings.

Shipping Type Analysis — Compare average purchase amounts for Standard and Express shipping.

Subscription Analysis — Compare customer counts, average purchase amounts, and total purchase amounts between subscribers and non-subscribers.

Product Discounts — Identify products with the highest percentage of purchases involving discounts.

Customer Segmentation — Classify customers as New, Returning, or Loyal based on previous purchases.

Top Products by Category — Rank the three most purchased products in each category.

Repeat Buyers and Subscriptions — Examine subscription status among customers with more than five previous purchases.

Revenue by Age Group — Analyze purchase revenue across customer age groups.

📈 Power BI Dashboard

Power BI is used to visualize the findings and present customer shopping behavior in an interactive format.

The dashboard complements the Python and SQL analysis by helping users explore purchasing patterns, spending trends, product performance, and subscription behavior.
